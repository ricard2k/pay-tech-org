## Key Concepts

Before diving into cryptographic details, it's important to understand:

### Transaction Lifecycle
Every payment goes through several stages:
1. Card authentication
2. Data encryption
3. Transaction authorization
4. Verification (ARQC/ARPC)
5. Settlement

### Security Layers
Payment systems use multiple security mechanisms:
- **Encryption**: Data at rest and in transit
- **Authentication**: Verifying cardholder identity
- **Non-repudiation**: Ensuring transactions can't be denied
- **Tamper detection**: Identifying fraudulent changes
